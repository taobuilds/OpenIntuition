# OpenIntuition artwork

## Files

- `openintuition-logo.png`: transparent square mascot for avatars and README use.
- `openintuition-banner.png`: wide header with the mascot and project wordmark.

The final direction uses thin irregular pen lines, flat color areas, asymmetric eyes, a teal owl, a cream face, and an orange intuition spark. The user supplied two illustrations as style references. Those reference screenshots are not distributed with this repository. The owl is a newly generated character; it does not reproduce the reference characters.

Created with the built-in imagegen tool. The final PNG files are saved here in the project, rather than being served from a local generation cache. Project artwork is provided under the repository's [MIT license](../LICENSE).

## Final logo prompt

```text
Use case: logo-brand / style-transfer. Create the revised OpenIntuition mascot logo. Input 1 is the previous owl: keep only the concept of a teal owl with cream face, amber/orange beak and a tiny intuition spark; redesign its drawing completely. Inputs 2 and 3 are ART STYLE references only: focus on the drawn art inside the screenshots, ignore all black bars and phone interface. Match their thin wobbly black pen outlines, flat solid color areas, scratchy sparse hatching, offbeat handmade cartoon proportions, quietly absurd dry humor and lo-fi indie storybook look. The owl should feel like a quirky character from a hand-drawn animation: slightly lopsided head, two uneven large cream eye patches with small wondering pupils and a single roughly drawn ring around each pupil, narrow awkward little wings, oval teal body, skinny orange feet, a tiny hand-drawn orange spark by the head. Friendly thoughtful oddball, not angry, not glossy, not baby-cute. A compact readable single original owl centered with transparent padding on a square canvas. Thin irregular dark outlines, flat teal, cream and orange, at most a few short feather pen marks. No gradients, no highlights, no shadows, no clean vector symmetry, no corporate logo polish, no 3D, no text, no border, no UI, no watermark. Genuine transparent background. Do not copy the fish-headed man or walking characters, borrow only their line/color treatment.
```

## Final banner prompt

```text
Use case: logo-brand. Asset: finished wide GitHub README header banner, 2.5:1 landscape approx 1600 by 640. Input 1 is the revised OpenIntuition hand-drawn owl mascot, preserve that exact quirky identity: uneven eyes, teal body, cream face, orange beak and feet, one orange intuition spark, thin wobbly black pen line, sparse feather hatching. Inputs 2 and 3 are art-style references only, use the drawings inside screenshots, exclude all black phone UI. Use flat saturated deep indigo-purple background like input 2, handmade indie cartoon pen linework, bold flat color blocks, dry humor, slightly awkward charming character, no glossy or corporate finish. Place the owl on left third in a slightly tilted curious pose. Right two thirds: large clearly readable warm cream lightly hand-lettered wordmark exactly 'OpenIntuition'; underneath smaller cream simple legible lettering exactly 'When preferences change, memory should too.' Keep spelling exact, only these two lines of text. A single loose orange drawn loop near the owl may suggest memory, but leave abundant clean background, very few doodles. Flat solid fills, no gradients, no 3D, no large drop shadows, no vector-perfect symmetrical mascot, no badges, no mockup, no watermark, no screenshot UI. All text comfortably inside edges. Do not copy the reference people or fish.
```
